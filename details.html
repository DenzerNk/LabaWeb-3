Опис вудки

Destiny Rod — одна з найпрестижніших спеціальних вудок у грі Fisch для досвідчених гравців. Її головна перевага — рекордний показник удачі (Luck), який становить +250%.

Для купівлі цієї вудки гравець повинен заповнити щонайменше 70% бестіарію та накопичити значну суму ігрової валюти. Вона ідеально підходить для полювання на міфічних риб у глибоководних локаціях.
